# MarketSprint MVP

MarketSprint is a gamified stock-market learning and paper-trading concept for Indian college students.

## Deploy on Vercel
Set the Vercel **Root Directory** to `marketsprint`. Framework: Other. Build command: blank. Output directory: `.`.

The landing page links to the MarketSprint validation survey created in Jotform.

## Product loop
Learn → Practice → Review → Improve.

Educational simulation only; not investment advice.
